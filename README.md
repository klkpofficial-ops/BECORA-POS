
BECORA – Cake Shop Management & POS System

BECORA is a web-based Cake Shop Management and Point of Sale (POS) System developed using Python Flask and SQLite.

Features

- Dashboard with business overview
- Product management (Add, Edit, Delete)
- Stock management
- Low stock alerts
- Point of Sale (POS)
- Shopping cart and quantity management
- Cash and Card payments
- Automatic change calculation
- Receipt generation and printing
- Sales history
- Daily and monthly sales reports
- Database backup and download

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Git and GitHub

Installation

1. Clone this repository.
2. Open the project folder.
3. Create a virtual environment:

   python -m venv venv

4. Install dependencies:

   pip install -r requirements.txt

5. Run the application:

   python app.py

6. Open your browser and visit:

   http://127.0.0.1:5000

Database

BECORA uses SQLite to store product and sales information.
